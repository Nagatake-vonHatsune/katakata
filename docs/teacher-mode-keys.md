# Kata-Kata teacher mode: keys and clicker · 先生モード：キーとリモコン

Print this page and keep it by the laptop. · このページを印刷して、パソコンのそばに置いてください。

Turn teacher mode on in **Settings → 🎓 Teacher mode**. Pick a chapter, scene, board or part on Home, pick an activity, press **Start**.
**設定 → 🎓 先生モード** をオンにして、ホームで章・場面・ボード・パートと活動を選び、**スタート**。

| Key · キー | What it does | 動作 |
| --- | --- | --- |
| **→**  **Space**  **PageDown** | Next. On a slide with an answer, the first press reveals it, the second moves on. | 次へ。答えのあるスライドでは、1回目で答えを表示、2回目で次へ。 |
| **←**  **PageUp** | Back one slide (shown again unrevealed). | 1枚戻る（答えは隠れた状態）。 |
| **1  2  3  4** | Choose an option (reply, Laju!, Nombor & Masa; Cari Benda up to 9). In a frame: place the nth tile still in the bank. | 選択肢を選ぶ（返事・Laju!・Nombor & Masa。Cari Benda は 9 まで）。文型では、残っているタイルの n 番目を置く。 |
| **R** | Reveal the answer. | 答えを表示。 |
| **H** | Hide or show the English and Japanese translations. | 英語・日本語の訳の表示／非表示。 |
| **P** | Play the Malay again (▶ and 🐢 buttons on screen for slow). | マレー語をもう一度再生（画面の ▶ と 🐢 でゆっくり）。 |

**Presenter clicker · プレゼン用リモコン:** most clickers send PageDown and PageUp, so a two-button clicker is enough: forward reveals, then moves on; back goes back.
ほとんどのリモコンは PageDown / PageUp を送るので、2ボタンで足ります（進む＝答え→次へ、戻る＝前へ）。

**On screen · 画面上:** the big **Next ›** and **Reveal** buttons do the same as the keys. The **🎓 先生モード ✕** badge turns teacher mode off in one tap; **✕** on the right ends the class run.
大きな **次へ ›** と **答え** ボタンもキーと同じです。**🎓 先生モード ✕** をタップすると先生モードがオフに、右の **✕** で授業の実行を終わります。

Class runs never change the device's learner (no reviews, stamps, 🔥, points, streaks or records). · 授業の実行はこの端末の学習者のデータを変えません。
