# Kata-Kata clean-up after Cikgu Sensai Stage 1 (12 Nov 2026)

**What this is.** The report and hand-off for the clean-up Sam authorised, run from the brief
`docs/kata-kata-cleanup.md` in the Cikgu Sensai repository plus the five rows Sam approved afterwards
(L-1084 to L-1088). The Malay ledger (Google Sheet, snapshot in `content/ledger/malay-ledger.csv`) was the source
of truth for every new card's Malay, meanings, part of speech, affix tag and chapter.
All new Japanese is a Claude draft for native review.

**Result:** 805 → **920** live cards (123 added, 8 removed), 33 → **34** packs (one new Dunia scene). `npm run check`
(types, 39 unit tests, content check, build) and both end-to-end tests (`smoke.cjs`, `fun.cjs`) passed before every push.

## How it was done

- `tools/make_vocab_bank_v5.py` builds `content/source/2026-11-12_KataKata_VocabBank_v5.xlsx` from v4, one function per
  chapter, always starting from the pre-clean-up ledger snapshot (git `aa87ffb`), so it can be replayed:
  `python3 -I tools/make_vocab_bank_v5.py content/source/2026-11-06_KataKata_VocabBank_v4.xlsx <out.xlsx>`.
  Then `tools/import_vocab_bank.py` writes the packs, and `tools/import_hanashishou_bridge.py` (against Hanashishou
  `e5e167c`, the commit the packs came from; it reproduced them byte for byte first) drops Jambatan words that became
  class cards.
- Importer additions: an optional **Note** column on the Dunia tab (festival notes) and an optional
  `sedia_kelas_review` key in `tools/import-overrides.json` (cards that moved or merged stay in the old chapter's
  Sedia Kelas list as review cards).
- `tools/ledger/sheet_to_snapshot.py` turns a read of the sheet's Ledger tab into the repo snapshot.
- After each chapter the sheet's **Kata-Kata (card IDs)**, **Kata-Kata place** and **Action (open)** columns were written
  (with a read-back check that only the planned cells changed; "(pending)" is gone from every row), and Journal rows were
  appended (Journal rows 90 to 124 for this session, each with the commit).
